## Projects

### [TraderCall.io](https://tradercall.io)

Side project. Scores 1,500+ US and Indian stocks every evening on six indicators (RSI, MACD, EMA cross, Bollinger Bands, OBV, relative volume), filters by market regime and ranks BUY and SELL signals.

- Backtests use only data available on the signal date and enter at the next day's open, so there is no lookahead bias
- Paper trading, plus Gemini summaries of chart patterns, news sentiment and portfolios, cached to keep API cost down
- FastAPI and PostgreSQL on Fly.io; Next.js 15 static export on Cloudflare Pages

The repo is private. I'm happy to walk through the code.

### [Thirukkural](https://github.com/Rakesh-git-2/thirukkural)

A web app and public REST API for all 1,330 couplets of the Thirukkural, with full-text search in Tamil and English. Next.js 15 on Cloudflare Pages, API on Cloudflare Workers. [Live site](https://thirukkural-54t.pages.dev)
